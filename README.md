# 제어공학개론 강의노트 (2026-2)

> **읽기 전용 공개본입니다.** 2026년 10월 11일(제1~10강) 시점의 노트를 이력 없이 옮긴 사본이며, 이후 갱신은 반영되지 않습니다.
> 최신 PDF: [`docs/control_notes_KR.pdf`](docs/control_notes_KR.pdf) · [`docs/control_notes_EN.pdf`](docs/control_notes_EN.pdf) · 웹 뷰어: <https://suhan-dev.github.io/control-notes-2026-2/>

서울대학교 **제어공학개론** 수업의 학기 누적 강의노트입니다.
회차별로 문서를 나누지 않고, 한 학기 내내 하나의 문서를 주제별로 이어 쓰며
새 강의 내용을 해당 절에 녹여 넣고 다시 빌드합니다.

- `control_notes_EN.tex` — 영문판 원고 (**xelatex**)
- `control_notes_KR.tex` — 국문판 원고 (**xelatex**)
- `controlnotes.sty` — 두 판이 함께 쓰는 양식 (`fontspec`·`xetexko` 를 쓰므로 둘 다 xelatex 로만 빌드됩니다)
- `docs/` — 배포되는 웹 뷰어 (`index.html`) 와 최신 PDF. **직접 손대지 마세요, `publish.sh` 가 채웁니다.**

## 강의 하나 추가하기

1. 해당 `.tex` 파일을 열어 새 강의 내용을 알맞은 절 아래에 이어 씁니다.
   (이미 다룬 내용은 반복하지 않고 상호참조만 합니다.)
2. 저장소 루트에서:

   ```sh
   ./publish.sh
   ```

   두 판을 `xelatex` 로 각각 세 번 돌리고(목차 쪽번호가 수렴하는 데
   3패스가 필요합니다), PDF 를 `docs/` 로 복사하고, `docs/manifest.json` 을 갱신한 뒤,
   git remote 가 설정되어 있으면 커밋·푸시까지 합니다.
   (remote 가 없으면 무엇을 하면 되는지 안내만 출력하고 정상 종료합니다.)
3. 푸시가 끝나면 사이트는 몇십 초 안에 새 노트로 바뀝니다.
   뷰어가 `manifest.json` 의 버전을 붙여 PDF 를 받으므로 캐시 때문에 옛 판이 보이는 일은 없습니다.

빌드가 실패하면 `publish.sh` 가 로그의 첫 오류를 보여 주고 멈춥니다.

## 노트 구조와 추가 규칙

노트는 날짜순이 아니라 주제순이고, 수업의 단계마다 **대단원(부)** 을 하나씩 둡니다
(`\partdivider`). 절 번호는 대단원과 무관하게 문서 처음부터 끝까지 이어집니다.
각 강의의 새 내용이 시작되는 자리에는 강의 번호와 날짜를 단 가는 가로줄
(`\lecturebreak`) 을 그어 두었습니다. 강의를 하나 더할 때의 규칙은 이렇습니다.

1. 새 강의 내용은 **주제가 맞는 대단원의 절에 녹입니다** — 새 장으로 덧붙이지 않습니다.
2. 정말로 새 주제가 시작되면 `\partdivider` 로 **새 대단원을 엽니다.** 절 번호는
   이어서 붙입니다 — 대단원마다 1부터 다시 세지 않습니다.
3. 그 강의의 새 내용이 시작되는 자리에 `\lecturebreak` 를 넣고, **앞부분 회차 표에
   같은 자리를 가리키는 행을 한 줄 추가합니다.** (`lectures.py` 가 국문판 표의 마지막
   행을 읽어 `manifest.json` 의 `lectures` 를 만듭니다. 본문 마지막
   `\lecturebreak` 의 회차·날짜가 표와 어긋나면 경고만 내고 배포는 계속합니다.)
4. 여러 강의를 **한 단위로 묶어 정리할 때는** 구분선 하나와 회차표 범위 행 하나로
   적습니다. `lectures.py` 는 그 범위의 끝 번호·끝 날짜를 읽고, 마지막 구분선의
   (끝 번호, 끝 날짜) 가 표 마지막 행과 같은지만 대조합니다(구분선 개수는 세지 않습니다).

   ```tex
   % 영문판
   \lecturebreak{Lectures 7--10}{23 September -- 7 October 2026}
   7--10 & Wed, 23 Sep -- Wed, 7 Oct 2026 & \S\ref{sec:vspace}\\
   % 국문판
   \lecturebreak{제7$\sim$10강}{2026년 9월 23일$\sim$10월 7일}
   제7$\sim$10강 & 2026.\,09.\,23 (수) $\sim$ 10.\,07 (수) & \S\ref{sec:vspace}\\
   ```
5. 앞부분 "강의의 흐름" 목록에서 해당 대단원을 **진행 중/완료로 고칩니다.** 예정
   항목은 근거가 있는 것 — 강의에서 실제로 밝힌 계획 — 만 적습니다.
6. **두 판의 대단원·절·label 구조는 1:1** 로 유지합니다.

대단원은 목차와 PDF 책갈피에 절보다 한 단계 위로 들어가고, **번호는 붙지 않습니다.**
웹 뷰어가 번호 있는 책갈피만 절로 인식해 EN/KO 전환 때 읽던 자리를 옮기므로, 대단원
책갈피에 번호를 붙이면 절로 오인됩니다.
